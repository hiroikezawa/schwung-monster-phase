# MONSTER PHASE 移植用参照ファイル

Claude CodeにはこのディレクトリをSchwungの作業リポジトリ内に配置して参照させてください。

- `BITRAZER_MONSTER_PHASE.bin`: AIRA Modular Customizerから保存したパッチ（1212 bytes）
- `MONSTER_PHASE_reference.png`: 元の配線スクリーンショット
- `MONSTER_PHASE_implementation_spec.md`: 移植用仕様（未確定事項を含む）
- `BITRAZER_MONSTER_PHASE_analysis.json`: バイナリ解析結果

配線の完全復元や原機DSPと音響的な一致を保証するものではありません。
